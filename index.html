📝 미션 #4 - '나'에 대해 기록하기

🗓️ 2026.11.07 | 작성자: 김민경 (상명대 CodeCure)

1. 현재 나는 무엇을 중요하게 생각하는가?

(1) 나의 삶과 진로에서 중요하게 생각하는 가치나 선택 기준

  • 학문적·기술적 전문성의 깊이 (대학원 진학 및 연구)
  • 주체성과 책임감 (스스로 주도하는 문제 해결)
  • 정당한 보상과 경제적 자립 (사회적 인정과 가치 입증)
  • 지속 가능한 성장과 도전 (현주소에 안주하지 않는 확장)
  • 일과 삶에서 느끼는 행복감 (과정에서의 몰입과 성취감)

(2) 각 기준을 중요하게 생각하는 이유 및 경험

• 학문적·기술적 전문성의 깊이 (대학원 진학)

학부 과정에서 배우는 지식은 보안의 넓은 기본기라고 생각합니다. 따라서 향후 대학원에 진학해 디지털 포렌식(DFIR)을 비롯한 특정 보안 영역의 깊이 있는 메커니즘을 연구하고, 단순 사용자를 넘어 원하는 분야의 전문가로 거듭나는 것이 중요한 진로 기준입니다.

• 주체성과 책임감 (스스로 주도하는 문제 해결)

누군가 시켜서 수동적으로 하는 공부나 AI에 과도하게 의존하는 지식은 온전히 내 것이 될 수 없다고 믿습니다. 내가 맡은 영역에서 스스로 리스크를 정의하고 끝까지 파고들어 문제를 해결할 때 비로소 성장한다고 생각합니다.

• 정당한 보상과 경제적 자립

삶의 경제적인 안정과 보상은 매우 중요합니다. 돈이란 단순한 소비의 수단을 넘어, 내가 쌓아온 커리어와 쏟아부은 시간이 사회적으로 얼마나 높은 가치를 지니고 있는지 증명하는 객관적인 지표라고 생각합니다.

• 지속 가능한 성장과 도전

빠르게 변화하는 기술 환경 속에서 이미 배운 지식에 안주하지 않고, 새로운 영역에 꾸준히 도전하며 어제보다 성장한 모습을 확인하는 것이 진로의 기준입니다.
경험: 매일 진행되는 전공 수업과 과제에 그치지 않고, 나만의 기술 블로그와 노트에 학습 기록을 꾸준히 남기는 루틴을 실천하고 있습니다. 전공의 시야를 넓히기 위해 동아리 활동 및 다양한 대외활동과 경진대회에 계속 도전하고 있습니다.

• 일과 삶에서 느끼는 행복감

아무리 거창한 목표나 높은 보상이 주어져도 과정 자체에서 행복을 얻지 못하면 오랫동안 즐겁게 할 수 없습니다. 관심 있는 문제에 깊이 몰입하고 이를 내 힘으로 해결했을 때 느낄 성취감은 내 삶을 움직이는 큰 행복의 원천입니다.

2. 나의 기준을 나이츠 프론티어에서 어떻게 실천하고 싶은가?

(1) 나이츠 프론티어에 지원한 이유

정보보안공학과 1학년으로서 아직 보안이라는 넓은 분야 안에서 내가 진심으로 열정을 쏟을 수 있는 세부 영역을 탐색하는 과정에 있습니다. 최근 디지털 포렌식(DFIR)처럼 사고 흔적을 추적하는 분야에 소소하게 관심이 생기기 시작했는데, 혼자서 막연히 공부하기보다 나이츠 프론티어에서 다양한 실습을 경험해보고 싶었습니다. 열정적인 동료들과 함께 포렌식을 포함한 여러 분야를 접하며 제가 진심으로 재밌어하고 하고 싶은 것을 찾기 위해 지원했습니다.

(2) 나이츠 프론티어에서 꼭 이루고 싶은 목표

7개월의 활동이 끝났을 때 "아 나는 이 분야를 제대로 파봐야겠다"하는 명확한 방향성과 목표를 확립하는 것입니다. 이번 활동에서 포렌식은 물론 다른 영역들까지 접해보며 내 적성을 확인하고, 활동이 끝난 후에도 스스로 계속 공부해 나갈 수 있는 단단한 기초체력을 다지고 싶습니다.

(3) 7개월 동안 해보고 싶은 경험

  • 다양한 보안 영역 실습 및 팀 프로젝트: 혼자서는 시도해보기 어려웠던 여러 분야의 보안 과제나 실습을 해보고, 팀원들과 작은 프로젝트라도 끝까지 해보는 경험을 하고 싶습니다.
  • 매달 과제 및 지속적인 기록 남기기: 7개월 동안 매주 부여되는 세션 과제나 실습을 포기하지 않고 완료하며, 새롭게 알게 된 내용이나 에러 해결 과정을 블로그에 꾸준히 정리해 나만의 보안 공부 기록을 쌓아가고 싶습니다.

🎓 [논문 심층 리뷰] VAPD: An Anomaly Detection Model for PDF Malware Forensics with Adversarial Robustness

🗓️ 2026.11.07  |  ✍️ 작성자: 김민경 (정보보안공학과)

📌 1. 선정 논문 정보
발표 학회 USENIX Security Symposium (보안 4대 탑 컨퍼런스)[cite: 1]
저자 및 소속 Side Liu (Wuhan Univ.), Jiang Ming (Tulane Univ.) 외[cite: 1]
원문 링크 USENIX '25 발표 페이지 바로가기 ↗[cite: 1]
💡 논문 선정 이유: 평소 깊은 관심을 가지고 있는 디지털 포렌식 및 DFIR 분야와 관련된 연구라는 점에서 이 논문을 선정하였다. 특히 보안 분야의 대표적인 최상위 학술대회 중 하나인 USENIX Security Symposium에 발표된 최신 연구라는 점이 좋았다. 기존 머신러닝 기반 악성 PDF 탐지 모델이 공격자의 의도적인 변형에 취약하고 악성 여부를 판별하더라도 PDF 내부의 구체적인 이상 위치를 식별하는 데 한계가 있다는 점에서 관심을 가지게 되었고, VAPD는 정상 PDF의 구조적 특징을 학습하고 재구성 오차를 이용하여 이상을 탐지하는 동시에 이상이 발생한 객체의 위치까지 식별한다는 점이 흥미로웠다[cite: 1]. 악성코드 탐지를 넘어 디지털 포렌식 분야와 연결할 수 있고 나중에 직접 해보거나 프로젝트하는 데 도움이 될 것 같아서 선정하였다.

2. 논문을 읽기 전 사전 정리 (기초 개념 및 용어)

📄 ① PDF와 악성 PDF 구조

글자·이미지 외에 객체, 스크립트, 첨부파일을 포함하는 문서 형식이다. 악성 탐지를 위해선 내부 객체와 구조 분석이 필수적이다.

  • 4대 영역: Header(버전 정보), Body(객체 저장), Cross-reference Table(객체 위치), Trailer(루트/시작 정보)
  • 핵심 용어: Object(데이터 단위), Stream(스크립트/이미지 영역), JavaScript, Payload(악성 실행 데이터)
🤖 ② 머신러닝 기반 악성코드 탐지

정상 파일과 악성 파일의 특징(Feature)을 분석해 새로운 파일의 소속을 판단하는 기법이다.

  • 지도학습: 정상·악성 정답 라벨 데이터로 학습
  • 분류 / 이진 분류: 입력 데이터를 정상 또는 악성 두 범주로 구분
⚔️ ③ 적대적 공격 (Adversarial Attack)

악성 PDF의 기능은 그대로 유지하면서 특징이나 구조를 미세하게 변형해 탐지 모델이 정상 파일로 오인하도록 유도하는 공격이다[cite: 1].

원본 악성 PDF → 구조/특징 미세 변형 → 기존 탐지 모델 (정상으로 오인!)
🛡️ ④ 적대적 강인성 (Adversarial Robustness)

공격자가 입력 데이터를 의도적으로 변형하더라도 탐지 모델이 속지 않고 본래의 올바른 판단을 유지할 수 있는 견고한 능력을 의미한다[cite: 1].

🔍 ⑤ 이상 탐지 (Anomaly Detection)

대부분의 데이터에서 나타나는 일반적 패턴과 크게 다른 데이터를 찾아내는 기술이다[cite: 1]. 다수의 정상 파일 패턴을 학습해 이를 벗어나는 악성 파일을 탐지하는 데 활용한다[cite: 1].

🧠 ⑥ 오토인코더와 VAE

입력 데이터를 압축했다가 원래 형태로 복원하는 신경망(Encoder → Latent Space → Decoder)이다. VAE는 잠재 공간을 확률분포로 모델링하며, 본 논문에서 정상 PDF 특징 학습에 사용된다.

📉 ⑦ 재구성 오차 (Reconstruction Error)

원본 데이터와 모델이 복원한 데이터 사이의 차이다[cite: 1]. 정상 PDF는 오차가 작지만, 학습한 적 없는 악성 PDF가 입력되면 복원이 제대로 되지 않아 오차가 급격히 증폭된다[cite: 1].

🕵️ ⑧ 디지털 포렌식과 위치 식별

악성 판정 이후 보안 분석가가 원하는 핵심 정보(의심 객체, 도달 경로, 변조 영역)를 규명하는 과정이다[cite: 1]. VAPD는 이상 위치 식별(Localization) 기능으로 이를 지원한다[cite: 1].

3. 본문 심층 리뷰 (기·승·전·결 구조)

(기) 등장 배경 및 기존 연구의 한계

PDF는 이메일 첨부파일이나 웹 환경에서 널리 쓰이지만 내부 자바스크립트나 객체를 악용해 악성코드를 은닉하기 쉽다. 탐지가 우회될 경우 랜섬웨어 감염이나 심각한 데이터 유출로 직결되며, 이상 위치를 알 수 없으면 분석가가 일일이 수동 분석해야 해 침해사고 대응이 지연된다[cite: 1].

기존 방식 / 연구 작동 방식 및 특징 결정적 한계점
Hidost PDF 구조 경로를 Bag-of-Paths로 추출 후 SVM 분류 구조적 특징을 변형한 적대적 공격에 취약, 위치 식별 불가
PDFrate 객체 수·스트림 크기 등 202개 수치 특징 추출 후 포레스트 분류 수치형 특징을 조작한 공격에 탐지 회피당함
RTM 구조적 강건성 속성 정의 및 기호적 구간 분석 학습 높은 계산 복잡도(학습 시간 약 11배 증가), 오탐률 1.74% 증가
기존 적대적 학습 공격자가 만든 적대적 샘플을 학습 데이터에 추가 훈련 고품질 샘플 생성 시간·비용 과다, 오탐률 증가 및 일반화 한계

(승) 핵심 아이디어 및 방법론 (VAPD 아키텍처)

저자들은 악성 패턴을 직접 학습하는 대신, 오직 정상 PDF의 구조적 특징만 VAE로 학습한 뒤 재구성 오차를 통해 탐지와 위치 식별을 동시에 수행하는 VAPD(VAE-based Anomaly detection for PDF malware Detection)를 설계했다[cite: 1].

1️⃣ PDF 구조 파싱 및 매핑

객체 연결 관계를 구조 트리로 만들어 경로 특징 벡터로 변환한다. 이때 경로와 실제 PDF 객체를 연결하는 Path-Object Mapping Table을 추가해 이상 객체를 역추적할 기반을 마련한다.

2️⃣ 정상 전용 학습 (Benign-Only)

악성 샘플 없이 순수 정상 PDF만 VAE에 학습시켜 정상 패턴을 내면화한다[cite: 1]. Latent Component를 결합해 성능을 보완하며, 악성 샘플 생성 비용 없이도 높은 강인성을 확보한다[cite: 1].

3️⃣ 이중 포렌식 목적 달성

재구성 오차로 악성 여부를 판별함과 동시에, 오차가 집중된 경로를 Path-Object Mapping Table과 대조하여 변조된 의심 객체의 정확한 위치까지 제공한다[cite: 1].

(전) 실험 결과 및 구조적 한계점

실제 지능형 지속 위협(APT) 샘플을 포함한 대규모 데이터셋에서 검증한 결과, 압도적인 성능과 효율성을 입증했다[cite: 1].

99.54% 기준 데이터셋 탐지 정확도[cite: 1]
100% / 6.01% MalGAN 저항률 / EvadeML 회피율
4.8% (4분) RTM(84분) 대비 학습 소요 시간[cite: 1]
81.8% / 74.5% 문서 단위 / 객체 단위 위치 재현율
⚠️ 논문의 한계점 및 아쉬운 점 (3가지)
  1. 복잡한 정상 PDF 오탐: 정상 파일이라도 구조가 매우 복잡하면 이상 파일로 잘못 판단(거짓 양성)하는 경우가 발생한다.
  2. 위치 식별 정밀도 차이: 전체적 특징 기반 복원 방식으로 인해 실제 이상 발생 위치와 모델이 지목한 위치가 완전히 일치하지 않을 수 있다.
  3. 난독화 취약성: 인코딩된 키워드 등 난독화 기법이 적용되면 특징 추출 과정에서 오류가 발생해 위치 식별 정확도에 영향을 줄 수 있다.

(결) 느낀점 및 향후 확장 방향

💭 느낀점: 이번 VAPD 논문 리뷰를 통해 단순한 시그니처 매칭이나 지도학습 기반 패턴 분류의 한계를 넘어서는 아이디어의 전환을 깊이 깨달았다. 공격자의 변조 패턴을 일일이 쫓아가는 기존 방식에서 벗어나 정상 모델의 복원 실패 오차라는 역발상을 통해 미지의 공격을 방어하고 포렌식적 위치까지 정확히 짚어내는 접근 방식이 매우 인상적이었다[cite: 1]. 특히 보안 분야에서 머신러닝을 적용할 때 데이터의 비대칭성을 어떻게 활용해야 하는지 큰 인사이트를 얻었다.

활동 회고 성장 계획

🛡️ 정보보안 입문자로서의 지난 활동 회고와 앞으로의 성장 계획

🗓️ 2026.11.08 | 작성자: 김민경 (상명대 CodeCure)

1. 🌱 보안의 첫 시작 이후

정보보안공학과 1학년으로 대학 생활을 딱 시작했을 때 나에게 보안이라는 분야는 정말 거대하고 멋있었지만 솔직히 한편으로는 어떻게 접근을 해야 하고 어떻게 시작해야 하는지 막막했다. 그리고 영화나 드라마에서 보던 해커나 포렌식 수사하는 모습만 떠올리며 호기심도 있었지만 두려움도 있었다.

보안을 시작하고 몇 개월 동안 학부 수업을 들으며 C언어, 파이썬, 자바 같은 기초 프로그래밍 언어를 체계적으로 익히고 동아리 활동을 통해 다채로운 보안 개념들과 기초적인 문제들을 접해 볼 수 있었다. 비록 이제 막 입문해서 기초 체력을 다지고 있는 1학년이지만 학부 수업이랑 동아리에서 배운 코딩과 이론들이 실제 시스템 취약점이나 공격 분석 그리고 포렌식 추적에 어떻게 연결되는지 조금씩 알게 되었다.

2. 🔍 내가 마주한 한계와 부족한 점

동아리의 심화 과제나 보안 4대 탑 컨퍼런스 논문을 리뷰하고 분석하면서 진짜 아는 게 하나도 없구나하는 것을 느꼈다. 거기에서 명확한 한계와 부족함을 느꼈다. 1학년으로서 마주한 부족한 점이 정말 많지만 그중 3개가 밑에 있는 것이다.

1) 프로그래밍 언어와 보안 개념 간의 연결 고리 부족

첫째, 프로그래밍 언어와 보안 개념 간의 연결 고리가 부족하다고 생각한다. 학교에서 배운 C언어나 파이썬, 자바 코딩과 보안 이론을 각각 별개의 과목으로만 공부하다 보니 둘을 하나로 엮는 응용 능력이 많이 부족하다고 느꼈다. 예를 들어 C언어로 열심히 작성한 코드에서 메모리 구조상 버퍼 오버플로우 같은 취약점이 정확히 어떤 원리로 터지는지 혹은 파이썬 파싱 라이브러리가 실제 악성 파일 탐지 도구나 포렌식 분석기에 어떻게 이식되어 작동하는지 실전 코드로 직접 연결하려고 했을 때 어떻게 해야 하는지 모르겠다고 생각 한 적이 많았다.

2) 실전 데이터 분석 경험 및 역추적 역량의 부족

둘째, 실전 데이터 분석 경험 및 역추적 역량이 부족하다고 생각한다. 이제 막 1학년 과정을 지나고 있다 보니 이론이나 단순한 기초 예제 코딩은 맛보았지만, 실제 악성 문서 파일을 구조적으로 파헤치거나 디지털 포렌식 관점에서 데이터의 흐름과 시스템에 남은 흔적을 세밀하게 역추적해 보는 실전 경험이 턱없이 모자랐다. 논문을 읽으면서도 이 복잡한 구조를 내가 직접 포렌식 도구로 분석할 수 있을까?라는 생각도 들었다.

3) 수동적인 문제 해결 습관과 주체적 탐구심 부족

셋째, 수동적인 문제 해결 습관과 주체적 탐구심이 부족하다고 생각한다. 과제나 문제를 풀 때 에러나 실패했을 때 왜 이 에러가 났을까를 깊이 파고들기보다는 당장 답을 내고 싶어서 또는 과제를 빠르게 하고 싶어서 선배분들한테 물어보거나 AI를 곧바로 의존해버리는 수동적인 태도가 있었다.

3. 🚀 부족한 점을 채워나갈 앞으로의 계획

1) 전공 코딩과 보안 이론을 잇는 미니 프로젝트 도전

첫째, 전공 코딩과 보안 이론을 잇는 미니 프로젝트를 도전해 볼 것이다. 학교에서 배우는 C언어, 파이썬, 자바 전공 지식과 보안 이론이 따로 노는 것을 막기 위해 직접 코드로 구현해보는 미니 프로젝트를 실습하겠다. 최근 리뷰했던 USENIX Security의 VAPD 논문에서 얻은 아이디어를 바탕으로, Python 파싱 라이브러리와 간이 오토인코더 구조를 활용해 미니 PDF 악성 구조 탐지 및 복원 오차 측정 도구를 내 손으로 직접 코딩해보며 프로그래밍 언어가 보안 분석에 이식되는 과정을 해 볼 것이다.

2) 수동적인 의존 탈피 및 역추적 디버깅 경험 확대

둘째, 수동적인 의존을 버리고 역추적 디버깅을 해보는 경험을 늘려볼 것이다. 그동안 과제나 문제를 풀 때 에러나 실패를 많이 했는데 그때마다 답을 빨리 내고 싶어서 선배님들께 물어보거나 AI에 곧바로 의존하던 수동적인 태도보다는 시스템 로그와 메모리 상태, 코드의 실행 흐름을 세밀하게 역추적하는 디버깅 습관을 들여서 왜 이 에러가 났을까를 내 힘으로 끝까지 파헤치는 주체적인 탐구 체력을 기를 것이다.

3) 나이츠 프론티어와 동아리 스터디를 통한 실전 데이터 분석

셋째, 나이츠 프론티어와 동아리 스터디를 통한 실전 데이터 분석 경험을 쌓을 것이다. 이론과 기초 코딩에만 머물지 않고 실제 악성 문서 파일 구조나 디지털 포렌식 관점의 데이터 흐름을 분석하는 실전 경험을 넓힐 것이다. 혼자서 해결하기 어려운 내용들은 동아리 동료들과 함께 스터디를 만들어서 서로 토론을 하고 나이츠 프론티어에서 주어지는 과제들을 포기하지 않고 끝까지 완수해 내며 실전 감각과 분석 역량을 기를 것이다.

4. 🌟 마치며

이번 회고를 작성하면서 보안 입문자로서 현재 내가 서 있는 출발점과 앞으로 채워나가야 할 점이 무엇인지 명확하게 알 수 있었다. 정보보안이라는 거대하고 깊이 있는 학문 앞에서 막막함과 한계에 부딪히기도 했지만, 내 부족함을 솔직하게 인정하고 나아갈 올바른 방향을 다잡는 소중한 계기가 되었다.

시작부터 완벽한 사람은 없다고 생각한다. 그렇기에 앞으로 나이츠 프론티어 과제와 동아리 스터디를 진행하며 마주할 수많은 실패와 디버깅 에러 역시 나를 한층 더 단단하게 만들어 줄 경험이라고 믿는다. 매일 배운 지식과 문제를 해결해 낸 과정을 깃허브 블로그에 꾸준히 기록하며 지식의 깊이를 다지고, 스스로 질문하며 끝까지 파고드는 주체적인 학습 루틴을 꼭 완성할 것이다.

훗날 디지털 포렌식 및 침해사고 대응 분야에서 복잡한 원인을 정확히 규명하고 사회에 기여할 수 있는 전문성과 책임감을 갖춘 보안 전문가로 성장하기 위해 멈추지 않고 꾸준히 나아갈 것이다.
